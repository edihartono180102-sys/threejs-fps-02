Emberworks — a round-based tactical FPS in Foundry Yard: plant the charge at Furnace Hall or the Silo Yard, or eliminate the Wardens. Four-versus-four against bots, money earned each round and spent in a buy menu (rifle, SMG, scoped DMR, grenade, armour), headshots that pay, recoil and spread that punish firing on the move, and rounds that end in a win or a loss and start again. Built with three.js 0.187.0, static files only — no build step, no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click to play. WASD moves, mouse looks, click fires, right-click aims, R reloads, E plants the charge, G throws a grenade, B opens the buy menu during freeze time, Ctrl crouches, Space jumps.
